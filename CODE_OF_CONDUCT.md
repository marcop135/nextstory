# Code of conduct

This project adopts the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), including its standards, scope, and enforcement guidelines.

Report conduct concerns privately to the maintainer using the email listed in [SECURITY.md](SECURITY.md#reporting-a-vulnerability), with `[conduct]` in the subject. The maintainer handles reports confidentially and applies the Covenant's enforcement guidelines.
